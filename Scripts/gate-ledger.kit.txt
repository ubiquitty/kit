# What the gates of ubiquitty-kit are held to.
#
# canary <gate>      a gate whose self-test a stanza of the driver already
#                    depends on; a scan that stops finding one is broken, and
#                    not a shrinking tree.
# budget <name> <n>  a count that must equal the tree's. It falls when the tree
#                    improves and never rises. A checkout holding several
#                    repositories sums their ledgers, since every count is over
#                    files and each file has one owner.
# tool <gate> <why>  a gate nothing invokes because a person runs it, and what
#                    invokes it instead.
canary check-swift-cxx-exports.py
budget gate-self-tests-uncovered 11
budget census-undated 0
budget vocabulary-span 0
budget vocabulary-array 6
